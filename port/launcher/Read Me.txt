BUFFY THE VAMPIRE SLAYER (Xbox, 2002) - PC port
================================================

This is an unofficial PC version of the 2002 Xbox game. It contains no game
data: you need your own Xbox disc of the game, as an image file (.iso).

THIS IS AN EARLY DEVELOPMENT BUILD. The game starts, shows its menus and
loads the first level, but so far that has only been checked by automated
tests with the window hidden and the sound off. Expect faults, and please
report them (see REPORT A PROBLEM).


INSTALL
-------
1. Start "Buffy Launcher.exe".
2. Under "Your Xbox disc image", press Browse and choose the .iso of your
   disc. The launcher tells you if it is the right game.
3. Under "Install to", press Browse and choose a folder (about 2.2 GB).
4. Press INSTALL and wait for the bar to finish.
5. Press PLAY.

Your disc image is only read. It is never changed, and you can delete it or
move it away after installing.

The next time you start the launcher it opens straight on PLAY.

Always start the game with the launcher's PLAY button. Starting
buffy_tvs.exe by itself does not work in this build.

The first start takes a little longer: the game sets up its own cache
(about 105 MB, in XboxData\Cache), as it did on the console's hard disk.


WHICH DISC
----------
The Xbox version, European (PAL) release. If your disc is another release
(for example the North American one) the launcher says so and does not
install: that release needs its own build of the port.
The 2003 sequel, Chaos Bleeds, is a different game with its own port.


SETTINGS AND CONTROLS
---------------------
Everything is set inside the game, in its own Options menu: Graphics
(display mode, resolution, VSync, picture shape, FPS limit), PC Audio,
PC Controls (with key bindings), Memory and Report a Problem. The launcher
has no settings.

The game first starts borderless, at your desktop's resolution, sound on.

An Xbox controller works as on the console. Other controllers (PlayStation,
Switch) go through SDL3.dll. Keyboard and mouse:

  Move            W A S D            Camera        mouse, or I J K L
  A               Space              B             Backspace
  X               E / left mouse     Y             Q / right mouse
  Black / White   Z / C              Triggers      Left Shift / F
  Start           Enter              Back          Escape
  Menus           arrow keys, Space to choose, Backspace to go back

  Alt+Enter or F11   fullscreen on / off
  F12                make a problem report

To leave the game: main menu, Exit.


SAVES
-----
Your saved games are in "XboxData\HardDisk" inside the game folder.
Installing again or updating never touches the "XboxData" folder or your
settings (btvs_settings.ini). To back your saves up, copy "XboxData".


REPORT A PROBLEM
----------------
In the game: Options, Report a Problem (also in the pause menu), or press
F12. The report is saved in the "reports" folder inside the game folder
(the launcher's "Reports folder" opens it) and holds a picture, the log,
what you did up to that point, and your settings, so the spot can be found
again. If the game crashes or stops responding it writes a report by itself
into the "crashes" folder.


IF SOMETHING GOES WRONG
-----------------------
- "This is another release of the game": see WHICH DISC above.
- "Default.xbe has been changed or damaged": the image was modified
  (patched, trained, or a bad copy). Use an unmodified image of your disc.
- "Not enough free space": the game needs about 2.2 GB on the drive you
  chose.
- The game closes or will not start: the launcher says so. The game folder
  ("Game folder" in the launcher) holds btvs_log.txt and btvs_console.txt,
  which record what the game did, and "crashes" if it wrote a crash report.
- A wrong screen size or a black screen: delete btvs_settings.ini in the
  game folder; the game starts with its defaults again.


UNINSTALL
---------
Delete the game folder. (Copy "XboxData" out first if you want your saves.)
Nothing is written anywhere else on your PC.
